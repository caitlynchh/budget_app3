# Budget App

Personal budget tracker with savings tracking and credit card debt management.

## Features

- Monthly expense tracking (fixed and variable)
- Savings fund tracking (tax, emergency, car repayment)
- Credit card debt payoff calculator
- Cash flow forecasting
- Data persists in browser (localStorage)

## Getting Started

### Local Development

1. Clone this repo
2. Install dependencies: `npm install`
3. Start dev server: `npm start`
4. Open http://localhost:3000

### Deployment to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Sign in with GitHub
4. Select this repo
5. Click "Deploy"
6. Vercel will automatically build and deploy

That's it! Your app gets a permanent URL and auto-updates whenever you push changes.

## Making Changes

1. Edit the code locally or on GitHub
2. Push to GitHub
3. Vercel auto-deploys (takes ~1-2 minutes)

## Data

All data is stored in your browser's localStorage. It persists across sessions.
